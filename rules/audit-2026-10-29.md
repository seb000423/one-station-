## 2. 좌표계·그리드
| 항목 | 현재 | 판정 |

## 4. 안전·이격
| 항목 | 현재 | 판정 |
|---|---|---|
| 제어반 전면 0.8 m | A셀 제어반 앞 페이스트 공급기까지 0.77 m, D셀 제어반 앞 페이스트 탱크까지 0.67 m; B·C·E 및 PLC 캐비닛 ≥ 0.9 m | ✗ (A·D) → 제어반을 0.3 m 뒤로(펜스 쪽) |
| 인접 로봇 셀 간 1.0 m | MIG 로봇 4대 피치 0.7 m (받침대 중심 간) | ✗ → 피치 1.0 m 이상으로 재배치(C셀 길이 +0.9 m) |
| 로봇 reach가 보행 통로·AMR 통로 침범 금지 | 라인 전체 펜스(양측) 안이라 외부 통로 침범 없음. 단 펜스 안의 수동 MIG 작업자 위치가 MIG 4호기 받침대에서 0.7 m, FR10 reach ≈ 1.0 m | ✗ → 수동 MIG 스테이션을 로봇 4호기에서 ≥ 1.3 m 떨어뜨리고 사이에 차광 펜스 |
| AMR 통로 단방향 1.5 / 양방향 2.5 m | 서쪽 코리더(벽 안쪽 −17.8 ↔ 라인 모델 −16.8) 1.0 m, 양방향 사용 → 위반. 북쪽 레인 4.2 m ✓, 남쪽 지게차 레인 ≥ 7 m ✓ | ✗ → 라인 모델을 동쪽으로 1.5 m 이동하거나 AGV 입고 경로를 북쪽 벽 쪽에서만 접근 |

| 항목 | 현재 | 판정 |
|---|---|---|
| shadowMap PCFSoft, 그림자 2048 | console.html / index.html 둘 다 PCFSoftShadowMap, 2048² | ✓ |
| AmbientLight 0.6 + Hemisphere + Directional | Hemisphere 0.25 + Directional 1.25 + 보조 Directional 0.45, AmbientLight 없음 | △ → AmbientLight 0.6 추가하고 Hemisphere/Directional 재조정(과노출 주의) |
| MeshBasicMaterial 금지 | 설비에는 없음. UI 오버레이 10곳(반경 링, 바닥 라벨, KPI 화면, 경로 마커)에서 사용 | △ → 오버레이는 비조명 표시가 목적이라 유지 권장, 필요하면 MeshStandard emissive로 교체 |
| 설비 재질 metalness 0.5–0.8 · roughness 0.2–0.4 | 알루미늄 0.8/0.36 ✓, 밝은 강 1.0/0.2, 어두운 알루미늄 0.75/0.42, 프레임 0.5/0.45, 도장 검정 0.25/0.55, 판금 0.15/0.55 | △ → 모델 재질표(models.js materials)를 규칙 범위로 통일 |
| 설비는 GLB 에셋 로드, BoxGeometry 금지 | 로봇 7대(FR5/FR10 GLB), 작업자·제어반·캐비닛·작업대·랙(GLB)은 준수. 컨베이어·스토퍼·캐빈·프레스·피더·갠트리 등 라인 설비 본체는 코드 생성 원시 도형을 GLB로 구운 것 | ✗ (가장 큰 차이) → 설비별로 realvirtual/Unity 에셋 대체 가능한 것(캐빈 → PalletScanner, 로봇 셀 → Line_07, 컨베이어 → 전용 벨트 모델 제작)부터 교체 |
| 바닥 #1e1e24 에폭시 + 은은한 그리드 | 바닥 0x2b373e(청회색) + GridHelper 1 m | ✗ → 바닥색 #1e1e24, 그리드 선 밝기 낮춤 |

## 제안 순서 (사용자 확인 후 진행)
1. 빌더 공통: 스냅 0.5 m, 바닥 #1e1e24, AmbientLight 0.6, 선택/충돌 강조색·외곽선, 원점 표시(좌하단 기준) — 모든 레이아웃에 영향.
2. 예시 공정 배치: MIG 피치 1.0 m, 수동 MIG 이격, 제어반 0.8 m, 서쪽 코리더 2.5 m(라인 이동).
3. 설비 재질표 통일 → 4. 라인 설비의 GLB 에셋 교체(가장 오래 걸림, 셀 단위).
