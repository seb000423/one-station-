# 설계 구조 카탈로그

자동 생성 파일입니다 (`npm run gen:twin`). 원본: `packages/schema/src/structure.ts`. 규칙 엔진: `packages/core/src/structure.ts`.

객체마다 **분류**가 있고, 분류마다 역할(어떻게 받쳐지는가) · 받을 수 있는 자리 · 남에게 내주는 자리 · 자리별 결합 방식이 정해져 있습니다. **검증된 조합**은 기준 설비(조립 · 도포 · 브레이징 · 검사)와 표준 관례에서 온 것이고, 목록 밖의 조합은 경고만 하고 막지 않습니다.

| 자리 | 조합 |
|---|---|
| 바닥 | `*` |
| 받침 윗면 | `lamp>frame`, `lamp>shelf`, `lamp>tray`, `lamp>base`, `shelf>shelf`, `work>tray`, `tray>jig`, `tray>tray`, `robot>base`, `jig>base`, `robot>column`, `robot>plate`, `jig>plate`, `jig>desk`, `gantry>column`, `gantry>frame`, `conveyor>frame`, `rail>frame`, `control>column` |
| 받침 옆면 | `control>shelf`, `control>frame`, `aux>frame`, `monitor>frame`, `fence>post`, `control>column`, `sensor>frame`, `sensor>conveyor`, `guard>frame`, `monitor>column`, `control>cabinet` |

| 작업대 앞 | `seat>desk` |
