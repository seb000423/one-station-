## D. 수용 기준 (Definition of Done)

- [ ] 모든 핸드오프에서 접촉이 있다. 그리퍼, 푸셔, 클램프가 제품에 닿아야 하며, 틈도 관통도 없어야 한다.
- [ ] 제품은 투입부터 배출까지 하나의 지속 객체다. 사라지거나 순간이동하지 않는다.
- [ ] 각 스테이션에서 정지 → 위치결정 → 작업 → 해제 단계가 눈에 보인다(스토퍼와 로케이트 핀 포함).
- [ ] 형상 간섭이 없다. 그리퍼와 제품 간 검사를 포함한 자동 bbox/클리어런스 검사를 통과해야 한다.
- [ ] 표지판이 설비나 작업자를 가리지 않고, 글자가 잘리지 않는다.
- [ ] 룰북(`smart-factory-standard-v2.md`)의 클리어런스 기준을 충족한다.
- [ ] BUILDER와 재저장한 MONITOR 양쪽에서 검증하고, 스테이션별 클로즈업 렌더를 첨부한다.
