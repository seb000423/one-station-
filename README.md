# ONE STATION — EGR 쿨러 니켈 페이스트 자동 도포 스테이션

원오토메이션(ONE AUTOMATION) × 코렌스(KORENS) EGR 쿨러 니켈 브레이징 페이스트 도포 스테이션의 웹 페이지와 Three.js 3D 콘솔입니다.

## 구성
- `site/index.html` — 메인 페이지 (실시간 3D 도포 장면 배경, STATION 3D 뷰어, ABOUT US)
- `site/console.html` — 스테이션 콘솔 (파라미터 설정, 사이클 시뮬레이션, 계량 판정)
- 두 파일 모두 단일 HTML이며 브라우저에서 바로 열립니다. 같은 폴더에 `hero.mp4`를 두면 메인 배경이 영상으로 바뀝니다.

## 스테이션 구성
- **R1 핸들링 FAIRINO FR5** (리니어 레일, 평행 그리퍼): 지그 → DMC 리더 → 저울 → 포지셔너 → 저울 → 지그
- **2축 U형 포지셔너** (틸트 + 회전, 클램프): 접합부마다 쿨러를 돌려 도포면을 R2 쪽으로 향하게 함
- **R2 도포 FAIRINO FR5** (10cc 시린지 디스펜서, 1" 니들): 접합부를 따라 Ni 페이스트 비드 도포
- 지그 4/6/8구, DMC → MES 추적성, 도포 전·후 계량(0.01 g), 3색 타워램프, 양개 도어

## 모션 계산
- FR5 DH 파라미터 기반 FK / 감쇠최소자승 IK (니들 축 자유회전 5자유도)
- FR5 관절 가동범위(J1·J5·J6 ±175°, J2·J4 −265~85°, J3 ±160°), 관절속도 180°/s 기준 사다리꼴 속도 프로파일
- 충돌 검사: 쿨러·클램프·포지셔너·작업대를 단순 형상으로, 로봇 링크·시린지를 캡슐로 근사
- 도포 구간별 포지셔너 각도·니들 기울기를 탐색해 충돌 없는 경로를 미리 계산(`assets/baked.json`)

## 빌드
```bash
python3 build.py   # src/ → dist/local/(단독 실행용), dist/artifact/
```

## 배포 (Vercel)
`vercel.json`이 `site/` 폴더를 그대로 정적 배포하도록 설정되어 있습니다. Vercel에서 이 레포를 Import하고 설정을 바꾸지 않은 채 Deploy하면 됩니다.
